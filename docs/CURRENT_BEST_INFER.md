# 当前默认推理策略

默认配置位于 `scripts/07_infer_export_stl.py` 与 `configs/repro.env`。

- 更新模式：右乘位姿偏移。
- 第一次平移/旋转更新系数：`0.4 * 0.75 = 0.30`。
- 后续平移/旋转更新系数：`0.10`。
- 最大迭代数：`10`。
- 停止条件：接受当前更新后，模型预测的平移残差 `< 1 mm`。
- 最终选择：最后一个安全接受的位姿。

轮廓 Chamfer、完整肝脏掩码 IoU、网络预测旋转残差与 TRE/IC 都会记录，但默认不控制推理。
其中 TRE/IC 属于真值评估，只能在推理结束后使用。
